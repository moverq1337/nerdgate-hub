# NerdGate Hub

NerdGate Hub is a small open-source Traefik dashboard for routing domains to local ports and Docker-hosted services.

Project site:

```txt
https://moverq1337.github.io/nerdgate-hub/
```

If the Pages workflow fails with `Get Pages site failed`, enable Pages once in repository settings:

```txt
Settings -> Pages -> Build and deployment -> Source -> GitHub Actions
```

Alternatively, add a repository secret named `PAGES_TOKEN` with Pages/admin rights; the workflow can then enable Pages automatically.

The first MVP is intentionally narrow:

- one server
- DNS already points to the server
- Traefik terminates HTTP/HTTPS
- routes are managed from a small web panel
- dynamic Traefik config is generated by NerdGate Hub
- SQLite stores users, settings, and routes
- Docker containers with published TCP ports can be selected from the panel
- containers on the `nerdgate-proxy` Docker network can be routed without publishing ports

## Quick Start

One-line installer:

```sh
curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/install.sh | sh
```

or:

```sh
wget -qO- https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/install.sh | sh
```

The installer asks for the panel domain, checks that its DNS resolves to the server public IP, generates secrets, bootstraps the panel route, pulls the published Docker image, and starts Docker Compose.

Manual install:

1. Copy the example environment file:

```sh
cp .env.example .env
```

2. Edit `.env` and set a real email and admin password.

3. Start the stack from the published image:

```sh
docker compose up -d
```

4. Open the panel:

```txt
http://SERVER_IP:8080
```

Use the username and password from `.env`.

For local development from source:

```sh
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

## DNS Requirement

For the public panel domain, create an A record before installation:

```txt
nerdgate.example.com -> SERVER_PUBLIC_IP
```

The installer stops if the domain does not resolve to the current server. This is required for Traefik to receive Let's Encrypt HTTP-01 challenges on ports `80` and `443`.

## Routing To Host Ports

When the target app runs directly on the host, use:

```txt
http://host.docker.internal:3000
```

The Compose file maps `host.docker.internal` to the Docker host gateway on Linux.

## Routing To Remote Servers

Manual targets can point to another server by IP address or hostname:

```txt
http://203.0.113.10:8080
http://app.internal.example.com:3000
```

Traefik must be able to reach that address from the NerdGate Hub server. Open firewalls/security groups only for the NerdGate Hub server when possible.

## Routing To Docker Containers

NerdGate Hub reads the Docker Engine API through:

```txt
/var/run/docker.sock
```

The panel shows running containers that publish TCP ports to the host. Selecting a published port creates a target URL like:

```txt
http://host.docker.internal:3000
```

For containers without published ports, attach the app container to the shared proxy network:

```sh
docker network connect nerdgate-proxy CONTAINER_NAME
```

Then NerdGate Hub can create an internal target like:

```txt
http://CONTAINER_NAME:3000
```

Docker socket access is powerful. Treat the NerdGate Hub panel as an admin-only surface and protect it with a strong password.

## Diagnostics

After building the binary, DNS can be checked manually:

```sh
nerdgate-hub check-domain nerdgate.example.com
nerdgate-hub check-domain nerdgate.example.com 203.0.113.10
```

## Operations

Reset the admin password:

```sh
curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/reset-password.sh | sh
```

Uninstall:

```sh
curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/uninstall.sh | sh
```

The password reset command updates SQLite credentials and rotates the session secret.

## Docker Images

Images are published by GitHub Actions:

```txt
ghcr.io/moverq1337/nerdgate-hub:latest
```

The package must be public for anonymous pulls. Local source builds are still available through `docker-compose.dev.yml`.

## Generated Traefik Config

Routes, users, and settings are stored in:

```txt
./data/app/nerdgate.db
```

Traefik dynamic configuration is generated in:

```txt
./data/traefik/routes.yml
```

Traefik watches that file and applies changes automatically.
