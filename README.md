# NerdGate Hub

NerdGate Hub is a small open-source Traefik dashboard for routing domains to local ports and Docker-hosted services.

The first MVP is intentionally narrow:

- one server
- DNS already points to the server
- Traefik terminates HTTP/HTTPS
- routes are managed from a small web panel
- dynamic Traefik config is generated by NerdGate Hub
- Docker containers with published TCP ports can be selected from the panel
- containers on the `nerdgate-proxy` Docker network can be routed without publishing ports

## Quick Start

1. Copy the example environment file:

```sh
cp .env.example .env
```

2. Edit `.env` and set a real email and admin password.

3. Start the stack:

```sh
docker compose up --build
```

4. Open the panel:

```txt
http://SERVER_IP:8080
```

Use the username and password from `.env`.

## Routing To Host Ports

When the target app runs directly on the host, use:

```txt
http://host.docker.internal:3000
```

The Compose file maps `host.docker.internal` to the Docker host gateway on Linux.

## Routing To Docker Containers

NerdGate Hub reads the Docker Engine API through:

```txt
/var/run/docker.sock
```

The panel shows running containers that publish TCP ports to the host. Selecting a published port creates a target URL like:

```txt
http://host.docker.internal:3000
```

For containers without published ports, attach the app container to the shared proxy network:

```sh
docker network connect nerdgate-proxy CONTAINER_NAME
```

Then NerdGate Hub can create an internal target like:

```txt
http://CONTAINER_NAME:3000
```

Docker socket access is powerful. Treat the NerdGate Hub panel as an admin-only surface and protect it with a strong password.

## Generated Traefik Config

Routes are stored in:

```txt
./data/app/routes.json
```

Traefik dynamic configuration is generated in:

```txt
./data/traefik/routes.yml
```

Traefik watches that file and applies changes automatically.
