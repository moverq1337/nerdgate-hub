NerdGate Hub
Идея Старт Операции EN GitHub

Operations

Обслуживание должно быть понятным.

В MVP основные операции явные: диагностика, backup, restore, сброс пароля, удаление, проверка DNS и обновление контейнеров.

Диагностика

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/diagnose.sh | sh

Без helper script можно открыть Diagnostics в панели и использовать встроенную DNS-команду при необходимости:

docker compose run --rm --no-deps nerdgate-hub check-domain nerdgate.example.com docker compose logs --tail=160 traefik

Панель тоже показывает target health, статус Traefik config, Docker API и свежие Traefik logs. Shell-скрипт просто собирает host-level проверки в один интерактивный flow.

Backup и restore

В панели используй Diagnostics -> Download backup и Maintenance -> Restore backup. Restore upload проверяет zip, ставит его в pending, перезапускает NerdGate Hub и применяет restore до открытия SQLite.

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/backup.sh | sh curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/restore.sh | sh

Те же действия можно запускать напрямую через бинарь NerdGate Hub внутри Compose:

mkdir -p backups docker compose run --rm --no-deps -v "$PWD/backups:/backup" nerdgate-hub backup /data /acme/acme.json /backup/nerdgate.zip docker compose down --remove-orphans docker compose run --rm --no-deps -v "$PWD/backups/nerdgate.zip:/backup.zip:ro" nerdgate-hub restore /data /acme/acme.json /backup.zip docker compose up -d

Backup содержит SQLite-данные, optional legacy routes и Let's Encrypt acme.json. Restore останавливает Compose stack, заменяет данные и запускает stack обратно.

Security hardening

Панель использует CSRF-токены на POST-формах, rate limit для login и first setup, более строгие session cookies, security headers браузера и audit log важных действий.

Tagged releases

git tag v0.1.0 git push origin v0.1.0

Push тега создает GitHub Release и публикует такой же GHCR image tag.

Сброс пароля

Если доступ к панели еще есть, используй Maintenance -> Account password.

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/reset-password.sh | sh

Прямая команда без helper script:

docker compose run --rm --no-deps nerdgate-hub reset-password /data admin 'new-password'

Скрипт обновляет credentials в SQLite и ротирует session secret, поэтому старые сессии перестают работать.

Удаление

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/uninstall.sh | sh

Прямая команда без helper script:

docker compose down --remove-orphans

Скрипт останавливает Compose stack и может удалить папку установки вместе с данными. Прямая команда только останавливает контейнеры и оставляет файлы на диске.

Обновление

cd /opt/nerdgate-hub docker compose pull docker compose up -d
