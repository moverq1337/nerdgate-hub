Домены к контейнерам и портам без лишней платформы.

NerdGate Hub - минимальная панель поверх Traefik. Ее задача простая: направить домен на Docker-контейнер, локальный порт или внешний HTTP-сервис.

Зачем

Зачем это нужно

Меньше лишнего

NerdGate Hub не пытается стать большой платформой. Traefik принимает трафик, Docker запускает приложения, Hub управляет маршрутами.

Traefik-first

Маршруты генерируются как dynamic config для Traefik. HTTPS и Let's Encrypt остаются внутри Traefik.

Понятная установка

Инсталлер проверяет DNS до запуска, чтобы сертификат не ломался на первом старте.

Вместо Nginx Proxy Manager

Почему не просто NPM?

Nginx Proxy Manager полезен, но NerdGate Hub специально уже: Traefik-native, Docker-aware и без лишних настроек вокруг задачи домен -> сервис. Цель - меньше переключателей и более понятный workflow.

Архитектура

Как работает

  1. DNS домена панели указывает на сервер.
  2. Traefik слушает порты 80 и 443.
  3. NerdGate Hub хранит routes, users и settings в SQLite.
  4. NerdGate Hub пишет dynamic config в data/traefik/routes.yml.
  5. Traefik следит за файлом и применяет изменения автоматически.
