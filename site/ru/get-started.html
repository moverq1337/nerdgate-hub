Get Started

Установка за одну терминальную сессию.

Перед установкой создай DNS-запись для домена панели. Инсталлер остановится, если DNS не указывает на сервер.

1. Подготовь DNS

Создай A-запись:

nerdgate.example.com -> SERVER_PUBLIC_IP

Порты 80 и 443 должны быть доступны из интернета для Let's Encrypt HTTP-01 validation.

2. Запусти инсталлер

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/install.sh | sh wget -qO- https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/install.sh | sh

Инсталлер спросит папку установки, домен панели и email для Let's Encrypt. После запуска stack он покажет одноразовый setup token.

3. Открой панель

https://nerdgate.example.com

Вставь setup token из installer, затем создай первый admin username и password в браузере.

4. Создай первый route

Поле Domains принимает один домен или несколько доменов через запятые, пробелы или новые строки.

Порт хоста

app.example.com -> http://host.docker.internal:3000

Другой сервер

api.example.com -> http://203.0.113.10:8080

Docker network

Используй Attach в панели или docker network connect nerdgate-proxy CONTAINER_NAME

5. Диагностика, сброс пароля или uninstall

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/diagnose.sh | sh curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/reset-password.sh | sh curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/uninstall.sh | sh

Diagnostics-скрипт покажет Traefik logs и типовые причины проблем с сертификатами. Reset-скрипт обновляет admin credentials в SQLite. Uninstall-скрипт останавливает stack и может удалить папку установки.

Локальная разработка

cp .env.example .env docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build

Production-установка тянет ghcr.io/moverq1337/nerdgate-hub:latest, а dev-режим билдит из исходников. Замени пример setup token перед тем, как открывать приложение в интернет.
