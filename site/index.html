Open-source edge panel

Domains to containers and ports without the extra platform.

NerdGate Hub is a minimal Traefik-based dashboard for one-server routing: Docker containers, host ports, and remote IP targets.

English

What it does

Route domains

Point a domain to a Docker container, a host port, or a remote HTTP service.

Use Traefik

Traefik handles HTTPS, Let's Encrypt, and reverse proxying. NerdGate Hub manages the dynamic config.

Install safely

The installer checks that the panel domain resolves to the current server before starting the stack.

Русский

Что делает проект

Прокидывает домены

Домен можно направить на Docker-контейнер, локальный порт сервера или внешний HTTP-сервис по IP:port.

Работает поверх Traefik

Traefik принимает 80/443, выпускает сертификаты Let's Encrypt и проксирует трафик.

Проверяет установку

Инсталлер проверяет DNS домена панели до запуска, чтобы HTTPS не сломался на первом старте.
