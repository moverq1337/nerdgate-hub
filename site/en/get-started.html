Get Started

Install in one terminal session.

Before installation, create a DNS record for the panel domain. The installer stops if DNS does not point to the server.

1. Prepare DNS

Create an A record:

nerdgate.example.com -> SERVER_PUBLIC_IP

Ports 80 and 443 must be reachable from the internet for Let's Encrypt HTTP-01 validation.

2. Run installer

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/install.sh | sh wget -qO- https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/install.sh | sh

The installer asks for install directory, panel domain, Let's Encrypt email, admin username, and password.

3. Open the panel

https://nerdgate.example.com

Use the admin credentials from the installer.

4. Create your first route

Host port

app.example.com -> http://host.docker.internal:3000

Remote server

api.example.com -> http://203.0.113.10:8080

Docker network

docker network connect nerdgate-proxy CONTAINER_NAME

Local development

docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build

Production install pulls ghcr.io/moverq1337/nerdgate-hub:latest; local development can still build from source.
