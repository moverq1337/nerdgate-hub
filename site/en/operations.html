Operations

Keep the install understandable.

The current MVP keeps operational tasks explicit: diagnostics, reset password, uninstall, check DNS, and update containers.

Diagnostics

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/diagnose.sh | sh

This prints Compose status, Traefik logs, DNS check output, and common fixes for certificate issuance failures.

Reset password

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/reset-password.sh | sh

This updates SQLite credentials and rotates the session secret, which invalidates existing sessions.

Uninstall

curl -fsSL https://raw.githubusercontent.com/moverq1337/nerdgate-hub/main/scripts/uninstall.sh | sh

The script stops the Compose stack and can optionally remove the install directory with data.

Update

cd /opt/nerdgate-hub docker compose pull docker compose up -d

DNS diagnostics

docker compose run --rm --no-deps nerdgate-hub check-domain nerdgate.example.com docker compose run --rm --no-deps nerdgate-hub check-domain nerdgate.example.com 203.0.113.10
