Open-source edge panel

Domains to containers and ports without the extra platform.

NerdGate Hub gives a small admin UI over Traefik. It is built for one practical job: point a domain to a Docker container, local port, or remote HTTP service.

Why

Why this exists

Less surface area

NerdGate Hub avoids becoming a full platform. Traefik handles traffic. Docker runs apps. The Hub manages routes and admin workflows.

Traefik-native

Routes are generated as Traefik dynamic config. HTTPS and Let's Encrypt stay inside Traefik, where they belong.

Clear install path

The installer checks DNS, asks for the Let's Encrypt email, and gives you a one-time setup token for browser onboarding.

Compared to Nginx Proxy Manager

Why not just use NPM?

Nginx Proxy Manager is useful, but NerdGate Hub is intentionally narrower: Traefik-first, Docker-aware, and focused on clean one-server routing. The goal is a smaller mental model and fewer controls that do not matter for this use case.

Architecture

How it works

  1. DNS points your panel domain to the server.
  2. Traefik listens on ports 80 and 443.
  3. NerdGate Hub stores routes, users, and settings in SQLite.
  4. NerdGate Hub writes Traefik dynamic config to data/traefik/routes.yml.
  5. Traefik watches that file and applies changes automatically.
